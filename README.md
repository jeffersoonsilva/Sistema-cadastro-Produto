# Projeto de Controle de Produtos

## Descrição

Este é um projeto simples para o controle de produtos, onde o usuário pode:

- Cadastrar novos produtos com nome, código, quantidade e preço.
- Listar todos os produtos cadastrados.
- Alterar o preço de um produto existente.
- Excluir um produto do sistema.

A aplicação utiliza o padrão MVC (Model-View-Controller) para separar a lógica de negócios, a interface de usuário e o controle do fluxo da aplicação.

## Funcionalidades

- **Cadastro de Produto**: O usuário pode cadastrar novos produtos, fornecendo o nome, código, quantidade e preço.
- **Listagem de Produtos**: O usuário pode listar todos os produtos cadastrados.
- **Alteração de Preço**: O usuário pode alterar o preço de um produto utilizando o código do produto.
- **Exclusão de Produto**: O usuário pode excluir um produto fornecendo seu código.

## Como Executar

### Pré-requisitos
- Java 8 ou superior instalado.
- IDE recomendada: IntelliJ IDEA, Eclipse ou qualquer IDE que suporte Java.

### Passos para Executar

1. **Clone o repositório ou baixe os arquivos do projeto**.

2. **Compile e execute o arquivo `TesteProduto.java`**:
   - Abra o projeto na sua IDE.
   - Execute o arquivo `TesteProduto.java`, que é a classe principal.

3. **Interaja com o programa**:
   - O programa pedirá para digitar os dados dos produtos (nome, código, quantidade e preço).
   - Após cadastrar os produtos, você será apresentado a um menu com as seguintes opções:
     - Digitar `1` para listar os produtos.
     - Digitar `2` para alterar o preço de um produto.
     - Digitar `3` para excluir um produto.
     - Digitar `0` para sair do programa.
